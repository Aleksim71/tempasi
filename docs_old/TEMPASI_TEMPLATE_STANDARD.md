# TEMPASI — Template Standard v1.0

Этот документ описывает обязательный стандарт качества, структуры и упаковки
шаблонов, публикуемых на маркетплейсе Tempasi.

Цель стандарта:

- единообразие каталога
- понятность для покупателя
- минимальные риски поддержки
- высокая воспринимаемая ценность

Tempasi — курируемый маркетплейс.
Каждый шаблон должен соответствовать этому стандарту.

---

## 1. Общие требования

Шаблон Tempasi — это:

- практичный продукт для реального проекта
- чистый и читаемый код
- отсутствие лишних зависимостей
- понятная структура
- корректная лицензия

❌ Не допускается:

- demo-only шаблоны
- «визуал без сценариев использования»
- обфусцированный или минифицированный исходный код
- отсутствие адаптивности
- отсутствие документации

---

## 2. Структура шаблона (обязательная)

Каждый шаблон поставляется в виде ZIP-архива
со следующей структурой:

template-name/
├─ preview/
│ ├─ cover.png
│ ├─ home.png
│ ├─ inner-1.png
│ ├─ inner-2.png (если есть)
│ └─ mobile.png
│
├─ src/
│ ├─ index.html
│ ├─ assets/
│ │ ├─ css/
│ │ │ └─ style.css
│ │ ├─ js/
│ │ │ └─ main.js (если используется)
│ │ └─ images/
│ └─ components/ (опционально)
│
├─ README.md
├─ LICENSE.txt
└─ metadata.json

Имена файлов — в kebab-case.
Все пути — относительные.

---

## 3. Preview-изображения

Папка /preview обязательна.

Требования:

- формат: PNG
- цветовой профиль: sRGB
- без водяных знаков
- без элементов интерфейса Tempasi

Обязательные изображения:

- cover.png — основная карточка шаблона (1:1)
- home.png — главная страница
- mobile.png — мобильная версия

Рекомендуемые размеры:

- cover.png: 1200 × 1200
- остальные: от 1200 px по ширине

---

## 4. HTML / CSS / JS требования

### HTML

- валидный HTML5
- семантическая разметка
- отсутствие inline-стилей

### CSS

- один основной файл (style.css)
- допускается использование CSS variables
- без CSS-фреймворков (Bootstrap, Tailwind) в MVP

### JavaScript

- используется только при необходимости
- без сторонних библиотек по умолчанию
- читаемый, неминифицированный код

---

## 5. README.md (обязательно)

README должен содержать:

- краткое описание шаблона
- список страниц
- инструкции по использованию
- требования к окружению (если есть)
- описание лицензии

README пишется на английском языке.

---

## 6. metadata.json (обязательно)

Пример структуры:

{
"title": "SaaS Landing",
"category": "Landing",
"pages": 3,
"tech": ["HTML", "CSS", "JS"],
"responsive": true,
"license": ["PU", "CU"],
"price": {
"pu": 29,
"cu": 49
}
}

Все поля обязательны.
Цена указывается в евро.

---

## 7. Лицензирование

Каждый шаблон должен содержать файл LICENSE.txt.

На старте Tempasi поддерживает:

- PU — Personal Use (1 проект)
- CU — Commercial Use (клиентские проекты)

Extended лицензии — вне рамок MVP.

---

## 8. Контроль качества

Перед публикацией шаблон проверяется на:

- соответствие структуре
- корректность preview
- читаемость кода
- полноту README
- соответствие лицензии

Шаблон, не прошедший проверку,
не публикуется в каталоге.
